jarsnitch

See what a Minecraft plugin can do before you install it.

Files are analyzed here in your browser. Nothing is uploaded, and once this page has loaded it works offline.

See what an update adds before you install it.

This shows what the code can do, not proof of what it will do. A clean report isn't a guarantee.

jarsnitch reads the bytecode and never runs the plugin. Free and open source under MIT or Apache-2.0.
